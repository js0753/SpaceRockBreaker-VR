# Space Rock Breaker VR
Throw space rocks in trash or break them to uncover energy source to power up your ship so you can navigate it and reach the portal to take you home.

This game was created by following along the tutorials by Valem Tutorials.

Plays on PC and Meta Quest 2/3/3s.

Download : https://widerspider.itch.io/space-rock-breaker-vr
